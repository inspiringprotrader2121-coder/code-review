Privacy Policy

Last updated: 6 August 2026

This policy explains what Orvex Review ("Orvex", "we") processes when you use the service, and the choices you have. Contact: support@useorvex.com.

1. What we process

  • Repository content. When a pull request is reviewed we fetch the diff and may build a temporary filesystem snapshot of the repository tree and text files under the permissions you granted the GitHub App. Orvex uses that snapshot to identify imports, dependents, and other relevant context. Standard API review requests contain the diff and selected excerpts; when an agentic review is enabled, its read-only investigation path may inspect additional files in that temporary checkout.
  • AI inference providers. Excerpts of that content are sent to contracted third-party AI inference providers for transient processing. We apply automated secret redaction to content before it is sent. We do not permit providers to use your content for model training under their API terms.
  • Review artifacts. We store the findings, summaries, review metadata (repository name, PR number, commit SHAs, token counts, costs), and workspace settings needed to run the service and show your dashboard. A finding or suggested fix can include a code excerpt, file path, or line reference supplied by the model. We do not keep a complete copy of your repository.
  • Account data. GitHub account identifiers, workspace membership, email address for sign-in and billing, and session cookies (strictly necessary; we use no advertising or cross-site trackers).
  • Billing. Payments are handled by Stripe. We store Stripe customer/subscription identifiers, never card numbers. Stripe's own privacy policy applies to payment data.

2. What we do NOT do

  • We do not sell or rent your data.
  • We do not use your code to train models.
  • We process repository content only to perform requested review and related commands.

3. Retention

  • The repository snapshot and source content fetched for a review are held in temporary worker storage or memory for the duration of that review run and are normally removed when the run finishes. A process or host failure can leave temporary data until the operating system or an operator cleanup removes it.
  • Review findings and metadata are retained while your workspace is active so re-reviews, dashboards, and dedup work.
  • Operational backups can retain the database, including account, billing, review metadata, and stored finding excerpts, for the configured backup-retention period before rotation.
  • Uninstalling the GitHub App stops all processing. You can request deletion of stored workspace data at any time via support@useorvex.com; we delete within 30 days, except records we must keep for legal or billing compliance.

4. Security

Access tokens and signing keys are stored on hardened infrastructure with restricted access; webhook payloads are signature-verified; secrets detected in code are redacted before model calls. No system is perfectly secure — if we become aware of a breach affecting your data we will notify you without undue delay.

5. Your rights

Depending on your jurisdiction (e.g. GDPR/UK GDPR), you may have rights to access, correct, export, restrict, or delete personal data we hold about you. Email support@useorvex.com and we will respond within 30 days.

6. Changes

We will announce material changes to this policy on the dashboard or by email before they take effect.
